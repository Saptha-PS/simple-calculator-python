# Simple Calculator

A simple Python program to perform basic and advanced mathematical operations.

## About the Project

This project is a simple calculator that takes two numbers as input and performs the operation selected by the user.

## Concepts Used

-`input()` and `print()`
-Variables and data type conversion
-`if`, `elif` and `else` conditional statements
-Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
-Square root calculation
-User input validation

## What I Learned

-How to take input from the user.
-How to perform different mathematical operations using Python.
-How to use conditional statements to select an operation.
-How to handle invalid choices and division by zero.
